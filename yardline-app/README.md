# YARDLINE NFL — Projeto Unificado para IDE (VS Code / Cursor)

## Como Abrir e Rodar em 3 Passos:
1. Extraia este arquivo ZIP no seu computador.
2. Abra o **VS Code** ou **Cursor**, clique em **File > Open Folder** (Arquivo > Abrir Pasta) e selecione a pasta `yardline-app`.
3. Clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server** (ou dê dois cliques no `index.html` para abrir no navegador).

## Estrutura de Arquivos:
- `index.html`: Estrutura visual principal da plataforma.
- `css/styles.css`: Identidade visual, cores, tipografia e layout.
- `js/data_and_views.js`: Base das 32 franquias da NFL, atletas, notícias e telas.
- `js/engines.js`: Motores de cálculo (Playbook, Command Center, Projeções Editáveis, Trade Analyzer, Waivers e API Sleeper).
